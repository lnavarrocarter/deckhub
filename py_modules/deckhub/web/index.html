PlayStation 2 · PCSX2

Pega el contenido de un archivo .pnach para el juego. DeckHub lo guarda como <serial>_<CRC>.pnach y activa los trucos en la configuración del juego.

Nintendo Switch · Eden

Los trucos de Switch van por Build ID (el nombre del .txt, 16 caracteres hex). Debe coincidir con la versión del juego que tienes.

Acceso al panel

Si lo desactivas, el panel solo funciona en el propio Deck y el plugin de Decky sigue operando. Para volver a abrirlo usa el interruptor «Acceso desde la red» del plugin.

Portadas · SteamGridDB

Crea una clave gratis en steamgriddb.com → Preferencias → API. Se guarda solo en el Deck.
